# NANSEN_AI
"Nansen Sentinel-AI"
Autonomous Smart-Money Co-Pilot & Direct Execution Engine

**¿Qué es?**
Un agente de IA autónomo que monitorea en tiempo real los movimientos de las direcciones etiquetadas como Smart Money y Funds por Nansen. 
Cuando detecta acumulación en un token o posición en Hyperliquid, el agente valida la rentabilidad histórica de esas direcciones usando la Profiler API. 
Si el índice de efectividad supera el 70%, el agente ejecuta automáticamente un swap en Base/Solana o abre una posición Perp en Hyperliquid vía Nansen Execution API.
